# API Documentation

This document provides an overview of the **SQL State Management API** built using FastAPI. The API manages SQL states with IPFS versioning, enabling users to execute SQL queries, share data, and manage state hashes.

---

## **Overview**

The API consists of endpoints for:

- Executing SQL queries and managing state hashes.
- Sharing and revoking access to data using CIDs (Content Identifiers).
- Retrieving the latest hash and history of table operations.
- Listing tables owned by a user and accessing shared data.

---

## **Endpoints**

### **1. Root Endpoint**

Redirects to the API documentation.

```javascript
GET /
```

### **2. Execute SQL Query**

Executes an SQL query with optional state hash resolution. 

**API Endpoint**
```javascript
POST /query
```
**Request Body**
```javascript
{
  "query": "SELECT * FROM table_name",
  "user_id": "0x68ef100cC9dAdE0bb67a0aE99A02CDd1eaE54A2f" (optional),
  "state_hash": "QmHashExample123" (optional)
}
```
We can perform any sql queries (create, insert, select) using this API. 

### CREATE QUERY
**Request**

```javascript
curl -X 'POST' \
  'http://129.74.152.201:8000/query' \
  -H 'accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{
  "query": "create table users ( id INT, first_name VARCHAR(50), last_name VARCHAR(50), email VARCHAR(50), gender VARCHAR(50), age INT);"
}'
```
**Response**

```javascript
{
  "type": "create",
  "hash": "QmZHtoW6syvj52uN3qNobVYqVpGt5V9Trcei8JxeyaM1bK",
  "data": null,
  "includes_shared": false,
  "shared_count": 0,
  "own_count": 0
}
```

### **3. Get Latest Hash**

Retrieves the latest hash for a user and table.

**Request**
```javascript
url -X 'GET' \
  'http://129.74.152.201:8000/hash/latest/0x68ef100cC9dAdE0bb67a0aE99A02CDd1eaE54A2f/users' \
  -H 'accept: application/json'
```

**Response**

```javascript
{
  "hash": "QmPeN9S66FZt5GhPqmamojXYHUJ4NHQ6PPhrov96GToZQ7"
}
```

### **6. Share CID**

Shares a CID with another user.

```javascript
POST /share/cid
```

**Request**

```javascript
curl -X 'POST' \
  'http://129.74.152.201:8000/share/cid' \
  -H 'accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{
  "to_user": "0x68ef100cC9dAdE0bb67a0aE99A02CDd1eaE54A2f",
  "table_name": "users2",
  "cid": "QmSNksNxGCvTTFg8RXWcPgcxYnWsgk5Y8HfHY1WqQmDoNq"
}'
```

**Response**

```javascript
{
  "status": "success",
  "message": "CID shared successfully"
}
```

### **7. Revoke CID Access**

```javascript
  -H 'accept: application/json' \

  "from_user": "0x1f6Da6843Bad2a6F7a3fC7824289f197556f99b0",
  "table_name": "test",
  "cid": "QmXGzDq4A8Kg3ShoCibKM4mvCKBQ4y62Lz2x89VbwTS3MS"
}'
```

**Response**:

```javascript
{
  "status": "success",
```

## **Error Handling**

The API returns appropriate HTTP status codes and error messages in case of failures.

### Example Error Response:

```javascript
{
  "detail": "Hash not found"
}
```

**Common Errors**:

- **400 Bad Request**: Invalid request parameters.
- **404 Not Found**: Requested resource not found.
- **500 Internal Server Error**: Unexpected server error.

## **Dependencies**

The following external libraries and modules are used in this API:

- **FastAPI**: Web framework for building APIs.
- **sqlparse**: SQL query parsing.
- **pydantic**: Data validation and settings management.
- **Web3.py**: Interaction with the Ethereum blockchain.
- **IPFS Handler**: Custom module for managing IPFS data.
